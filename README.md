SnapCursorX is a visual cursor automation platform built for users who need more than a basic auto-clicker.
Design actions visually, create reusable workflows, and control exactly how your cursor behaves across different tasks, applications, and games.

* Create once, reuse anytime with setup system. Just save & load.

### Currently available modes
### 🎯 Single Mode
**Fast, simple, and powerful one-point automation.**
* Auto-click at a target position or live cursor
* Three execution modes:
  * Follow Mode
  * Marker Mode
  * Pointer Mode
* Repeat by count, timer, frequency, or continuous execution
* Adjustable click timing and hold duration
* Click Randomness support
* Built-in Screen Edge Failsafe
* Up to 1000 CPS using native execution engine (Up to user's PC performance*)
> Perfect for users who want quick deployment with minimal setup.

### ⏳ Sandbox Mode
**Build your own visual automation workflows.**
* Create markers, draggers, keybinds, and trigger points
* Design automation visually with draggable objects
* Execute multi-step workflows and sequences
* Fully customizable execution order
* Runtime keybind triggering system
* Overlay synchronization for live editing
* Expand and modify workflows anytime
> Not just clicking. You're building your own automation logic.
